## 🛠️ Technology Architecture

- **Frontend-Only**: No backend, no database (no MySQL, PHP, Prisma, or Node.js server). 
- **Static Deployment**: Runs on Vercel, Netlify, GitHub Pages, Cloudflare Pages, S3/CloudFront, Apache, or Nginx.
- **Interactive 3D**: Three.js WebGL canvas rendering a blow-molded 5L canister with liquid refraction, realistic HDPE plastic materials, ergonomic handle, and brand label.
- **Scroll Animations**: GSAP and ScrollTrigger for entrance reveals, subtle parallax, and sticky navigation states.
- **Typography**: Google Fonts (Manrope, Inter, Plus Jakarta Sans, Noto Sans Devanagari).
- **Communication Architecture**:
  - Official WhatsApp links with pre-filled message encoding (`https://wa.me/919423066050?text=...`).
  - Pre-formatted `mailto:` client openers with multi-line formatted inquiry summaries.
  - Direct telephone triggers (`tel:9423066050`).
  - Client-side validation with transparent user feedback.

## 🚀 Running Locally

You can preview the website locally using any static web server:

### Option 1: Python (Built-in)
```bash
python -m http.server 8000
```
Open [http://localhost:8000/](http://localhost:8000/) in your browser.

### Option 2: Node.js (NPX Serve)
```bash
npx serve .
```

## 🌐 Deploying to Production

### Deploying to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Click **Save**.

### Deploying to Netlify or Vercel
- **Netlify**: Drag and drop the project folder directly into the Netlify dashboard, or connect via Git (Publish directory: `.`).
- **Vercel**: Run `vercel` or import the Git repository with the "Other" framework preset.
